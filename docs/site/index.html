Model evidence: a frozen CPU baseline, with measured limitations

Trained on 263 Sen1Floods11 chips from six geographic collections. Evaluated once on 111 chips from the held-out Bolivia, India and Pakistan collections, after freezing the model and 0.5 threshold. Training and evaluation used no GPU.

One completed run.
A documented local workflow.

The 14 recorded stages completed in 171.07 seconds on one Mac, using cached radar, elevation and historical OSM. The run received 60,069,247 new Sentinel-2 response-body bytes under a declared 90 MB optical cap. This is a recorded case duration, not a cold-download or general runtime guarantee. This website displays the saved output; new acquisitions and native processing run from the repository.

What this evidence does not establish

  • Local flood or debris accuracy, physical road passage, or an operating destination.
  • A cold run on an arbitrary judge-selected AOI, provider availability, or a second-device test.
  • A complete optical map: only 11.10% of native optical cells are jointly assessed in this pair.
