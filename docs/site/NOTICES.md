# Akash public evidence viewer: sources and scope

This public website is a static reader of saved engineering evidence. It performs no satellite acquisition, native preprocessing, model inference, graph solve or live language-model call. The question selector is deterministic saved-fact lookup. The 14-stage Rasuwa case completed on 12 October 2026; the original records are copied unmodified into `case/`. The earlier two-case geographic explorer in `geography/` has separate dated records and remains unmodified.

`derive_evidence.py` verifies the full saved case SHA-256 before copying statistics and settlement summaries. It copies all supplied route vertices without simplification, and groups each whole segment by its recorded observation-support lengths for display. A mixed segment has multiple positive support categories; no within-segment spatial partition is invented. Full precision stays in `case/case-facts.json`; percentages in the interface are rounded. `derivation-manifest.json` binds both compact display files. The browser verifies their SHA-256 when Web Crypto is available. This is provenance checking, not independent scientific or security validation.

The coordinate map uses historical source-point and road-node coordinates. It has no terrain basemap, invented connectors, optimized route or validated physical entrance. No safe-passage, confirmed flood-isolation, operating-facility or local hazard-accuracy claim is made. A baseline graph disconnection is not new flood isolation. Native radar 10 m and optical 20 m layers are displayed separately without pixel fusion.
