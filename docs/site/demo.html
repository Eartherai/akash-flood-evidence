What the film demonstrates

The English explanation is burned into the picture; this film is silent. Its short browser recording shows actual controls over saved results. The 14-stage run used cached radar, elevation and pre-event OSM, with new optical acquisition. The film does not perform a new raw-data run or validate local hazards, road closures or passability.

The repository documents the separate Python/SNAP processing tier and optional local Qwen copilot. The public website is a static saved-evidence viewer. A YouTube upload is still required for the hackathon's video field.
